# Hurricane Marlow (fictional)

This exercise uses only the 18 requested South Texas counties. No Houston-area counties were added.

- `hurricane-marlow.json`: the three labeled fictional alerts and four fictional shelters. Times are Nov 8, 2026, 9 AM CST through Nov 9, noon CST. Shelter coordinates are area-weighted centroids of the loaded real county geometry.
- `hurricane-marlow.snapshot.json`: captured real Texas NWS, TIGERweb, Census ACS, FEMA, and resource results with original source status and retrieval times. OSM food-bank and medical lookups failed during capture; no locations were invented. Census values and live snapshots are never edited by the overlay.
- `hurricane-marlow.plans.json`: 18 county plans pre-generated by the same Gemini relief generator used by the app. Plans retain their source evidence and a SHA-256 fingerprint of the definition and real snapshot. A cache mismatch uses the Regenerate fallback.
- `hurricane-marlow.ranks.json`: computed by the existing pure priority module, including real alerts merged with fictional alerts and the real resource snapshot merged with fictional shelters.

The exercise clock is fixed at the scenario issue time only for explicitly simulated Marlow alerts. The simulation view checks captured real alerts at the snapshot capture time; real mode continues to use the actual clock. This permits demonstrating the scenario before its fictional start time without changing the alert records.

The baseline is Severity only: alert weight descending, then vulnerability descending and county name. Coverage gap retains the existing fixed score formula. With the captured real inputs, Brooks improves from rank 7 to 1; Duval moves from rank 8 to 10 because its nearest fictional shelter is approximately 25.9 miles away. The requested condition that both rise is **not satisfied** by these fixed inputs; the formula, Census estimates, and shelter locations were not manipulated to force that result.

Pre-generate/retry missing county plans with `node --env-file-if-exists=.env scripts/pregenerate-marlow.ts` from `silent-zone`. This invokes Gemini only for missing or invalidated plans. Keys stay in server environment files, outside these artifacts.
